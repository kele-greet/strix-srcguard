# P2-1 Docker API proxy — real daemon proof (2026-10-20)

## create mutation
POST /v1.55/containers/create through proxy
  body: Image=alpine:3.20, CapAdd=[NET_ADMIN, NET_RAW],
        Mounts: src -> /workspace/repo, src -> /workspace
response: 201 Created
docker inspect:
  CapAdd  = ["NET_RAW"]                 # NET_ADMIN removed
  Mounts  = [("/workspace/repo", true), ("/workspace", null)]
  # /workspace/repo ReadOnly=true; /workspace remains writable

## privileged / host namespace rejection
HostConfig {"Privileged": true}          -> 403 privileged containers are not allowed
HostConfig {"NetworkMode": "host"}       -> 403 network mode 'host' is not allowed
HostConfig {"PidMode": "host"}           -> 403 host PID namespace is not allowed
